  "Enable LSP only for local files; disable for remote (TRAMP)."
  (unless (file-remote-p (or buffer-file-name default-directory))
    (lsp)))

** [[https://github.com/jscheid/prettier.el][prettier]]

Reformat your code by running Prettier with minimal overhead, by request or transparently on file save.

Had to disable prettier for *css-mode* because syntax highlighting when exporting to HTML in org-mode did not work.

#+begin_src emacs-lisp
(use-package prettier
  :diminish
  :init
  ;; Use the correct variable so Prettier actually runs on save.
  (setq prettier-prettify-on-save-flag t)
  :hook (
         (js-ts-mode . prettier-mode)
         (json-mode . prettier-mode)
         (vue-mode . prettier-mode)
         (tsx-ts-mode . prettier-mode)
         (typescript-ts-mode . prettier-mode)
         ;;(css-mode . prettier-mode)
         (css-mode . prettier-mode)
         (yaml-mode . prettier-mode))
  :config
  ;; Teach prettier.el about the tree-sitter JS/TS modes so it can pick a parser.
  (setf (alist-get 'typescript-ts-mode prettier-major-mode-parsers)
        '(typescript babel-ts))
  (setf (alist-get 'tsx-ts-mode prettier-major-mode-parsers)
        '(typescript babel-ts))
  (setf (alist-get 'js-ts-mode prettier-major-mode-parsers)
        #'prettier--guess-js-ish))
#+end_src

Easily define an idiomatic command to reformat the current buffer using a command-line program, together with an optional minor mode which can apply this command automatically on save.

    :args (list "--write" "--parser" "sql")
